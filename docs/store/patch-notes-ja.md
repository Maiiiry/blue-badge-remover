# Blue Badge Remover v1.8.0 パッチノート

Xの画面変更で動かなくなっていたフォロー例外と自分のアカウントの認識を直しました。

## 変更

- アップデート時にフォローリストを一度空にして集め直します。以前の不具合で、フォローしていないアカウントがリストに混ざっていたためです。フォローしている課金バッジのアカウントが最初に一度だけ短く非表示になることがあるので、ダッシュボードの「フォローページを開く」で一度同期してください
- ツイート詳細の設定を2つ追加しました（初期値はオフ）。「投稿者のスレッドを表示」をオンにすると、開いたツイートの投稿者が前後に続けた投稿を非表示にしません。「詳細では折りたたんで展開できるように」をオンにすると、ツイート詳細で非表示にしたツイートをクリックで表示できます
- 「完全削除」で非表示にした場所に、見えない細い枠を残します。ツイート詳細から戻ったときにスクロール位置がずれないようにするためです
- Firefox for Android でもインストールできるようになりました

## 修正

- Xの画面変更後に自分のアカウントを認識できず、フォローが保存されず自分のツイートの例外も効かなかった問題を修正しました
- タイムラインを見るだけで、フォローしていないアカウントがフォローとして保存されていた問題を修正しました
- リポストした人を認識できず、フォロー・ホワイトリストのアカウントがリポストしたツイートまで非表示になっていた問題を修正しました
- ツイート詳細から戻ると、非表示の課金バッジツイートが一瞬表示されてからスクロールが跳ねていた問題を修正しました
- 英語・日本語のX画面で引用の非表示が効かなかった問題を修正しました
- 別の画面へ移動したとき、フィルターの適用が遅れていた問題を修正しました
- 自分のアカウントが課金バッジのとき、自分のプロフィールとツイートに警告バナーが出ていた問題を修正しました
- ブックマーク・いいね画面を認識できなかった問題を修正しました
- フィルター範囲をオフにした画面でも、リポストや引用が非表示になっていた問題を修正しました
- ダッシュボードの言語選択ボックスがずれて見えていた問題を修正しました
