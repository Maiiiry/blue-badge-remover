# Blue Badge Remover v1.8.0 패치노트

X 화면이 바뀌면서 깨졌던 팔로우 예외와 내 계정 인식을 고쳤습니다.

## 변경

- 업데이트할 때 팔로우 목록을 한 번 비우고 다시 모읍니다. 예전 버그로 팔로우하지 않는 계정이 목록에 섞여 있었기 때문입니다. 팔로우한 파딱 계정이 처음 한 번 잠깐 숨겨질 수 있으니, 대시보드의 "팔로잉 페이지 열기"로 한 번 동기화해 주세요
- 트윗 상세 설정 두 가지를 추가했습니다(기본 꺼짐). "글쓴이 타래 보기"를 켜면 들어간 트윗 글쓴이가 앞뒤로 이어 쓴 트윗을 숨기지 않고, "상세에서는 접어 두고 펼쳐볼 수 있게"를 켜면 트윗 상세에서 숨긴 트윗을 눌러서 볼 수 있습니다
- "완전 제거"로 숨긴 자리를 보이지 않는 얇은 칸으로 남깁니다. 트윗 상세에서 뒤로 왔을 때 스크롤 위치가 어긋나지 않게 하기 위해서입니다
- Firefox for Android에서도 설치할 수 있습니다

## 수정

- X 화면이 바뀐 뒤 내 계정을 알아보지 못해, 팔로우한 계정이 저장되지 않고 내 트윗 예외가 동작하지 않던 문제를 수정했습니다
- 타임라인을 보기만 해도 팔로우하지 않은 계정이 팔로우로 저장되던 문제를 수정했습니다
- 재게시한 사람을 알아보지 못해 팔로우·화이트리스트 계정이 재게시한 트윗까지 숨기던 문제를 수정했습니다
- 트윗 상세에서 뒤로 오면 숨긴 파딱 트윗이 잠깐 보였다 사라지고 스크롤이 튀던 문제를 수정했습니다
- 영어·일본어 X 화면에서 인용 숨김이 동작하지 않던 문제를 수정했습니다
- 다른 화면으로 이동할 때 필터가 늦게 적용되던 문제를 수정했습니다
- 내 계정이 파딱일 때 내 프로필과 트윗에 경고 배너가 뜨던 문제를 수정했습니다
- 북마크·마음에 들어요 화면을 알아보지 못하던 문제를 수정했습니다
- 필터링 범위를 끈 화면에서도 리트윗·인용이 숨겨지던 문제를 수정했습니다
- 대시보드 언어 선택 상자가 틀어져 보이던 문제를 수정했습니다
